# Nick Blanchard | Bloom Homes Assisted Living & Memory Care

Personal vCard site for Nick Blanchard, Owner/Operator of Bloom Homes Assisted Living & Memory Care in Brandon, Mississippi.

Live site: https://nickleous.github.io/vCard-Nick/

## Tabs
- About: background and Bloom Homes services
- Progress: build progress for Phase 1 (The Iris) and Phase 2 (Homes 2 & 3)
- Gallery: renderings, groundbreaking, and land photos
- Contact: quick contact buttons, map, and a form that saves messages to a Google Sheet

## Updating
- Progress: in `index.html`, change an item's `Up Next` label to `Complete` and add the date.
- Gallery: add a full size photo and a `-thumb` version to `assets/images/gallery/`, then copy an existing gallery item in `index.html`.
